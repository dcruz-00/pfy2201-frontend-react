# 16bit — Tienda retro en React

Tienda de consolas, videojuegos y accesorios retro, desarrollada con React y Vite.

**Sitio publicado:** https://dcruz-00.github.io/pfy2201-frontend-react/

## Funcionalidades

- Catálogo cargado desde JSON con estados de carga, error y reintento.
- Precio normal y precio oferta por producto.
- Buscador y filtro por categorías.
- Carrito: agregar, cambiar cantidades, quitar, vaciar y total.
- Opiniones cargadas desde una API externa (FakeStore API).

## Ejecutar en local

```bash
npm install
npm run dev
```

## Publicar en GitHub Pages

```bash
npm run deploy
```
